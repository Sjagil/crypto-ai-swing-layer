# v0.19.2 AI and Training Observability

The realtime TUI now exposes AI and training state directly from the local
swing-layer and canonical crypto repositories.

Displayed AI state includes configured advisory agents and recent agent/model
artifacts. Training/evidence state includes recent training, calibration,
qualification, selection, prospective/forward-evidence and model artifacts.

This is intentionally read-only observability. It does not start training,
change model qualification, enable ML live influence, or grant exchange
authority.
